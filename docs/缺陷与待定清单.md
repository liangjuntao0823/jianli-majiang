# 缺陷与待定清单

按「一个真打监利红中的牌友第一次上手会怎么骂」来写。第二轮已把 16 条体验缺陷全部改掉，
剩下的是**规则口径**（必须你拍板）和**工程风险**（需要 macOS 才能验证）。

---

## A. 规则歧义（9 处，仍按默认实现，等你拍板）

| # | 问题 | 当前实现 | 影响 |
|---|---|---|---|
| A1 | **打出红中要不要按「点杠 10 分」给分？** | 不给分，只补摸 + 结算翻倍 | 若给，四家各打一遍多收 4×10，分数结构会变 |
| A2 | **四张红中那 15 分，与逐张红中杠分叠不叠？** | 只在第 4 张结一次 `redGangBase=15` | 若叠加，最多多收 45 分 |
| A3 | 蓄杠（回头笑）触发条件 | 碰后补杠，5 分，无抢杠窗口 | 若指「杠上开花」，这段要重写 |
| A4 | 倍乘是否作用于杠分 | 作用于全部 `ScoreReason` | 已按「杠和胡都算」实现 |
| A5 | 单局是否封顶 | 无封顶，理论单笔 2560 分 | 会打出天文数字 |
| A6 | 流局判定 | 牌墙摸完即流局 | 若当地是「剩 N 张荒庄」，加参数即可 |
| A7 | 出牌/声明时限 | 出牌 20s、声明 8s，**已真正强制托管** | 已落地 |
| A8 | 点杠后其他家能否响应 | 不能（只能自摸，无胡窗口） | — |
| A9 | 连庄上限 | 无上限 | 连庄十把会很长 |

> 建议先拍 A1、A2，这两条直接决定分数对不对。

## B. 16 条体验缺陷 —— 全部已改

| # | 缺陷 | 这一版怎么改的 | 状态 |
|---|---|---|---|
| B1 | 真人不倒计时，一个人发呆全场卡住 | 房主端 0.5s 心跳检查，超 20s 自动按「最废的牌」打出并提示「超时托管」；客户端只画倒计时环，不抢着裁决 | ✅ |
| B2 | 手上有红中就胡不了，玩家以为程序坏了 | 手牌区常驻红字「手上有 N 张红中，打出后才能胡」，牌桌顶部红中计数条同步 | ✅ |
| B3 | 别人打的牌不能胡，一直等 | 底部状态文案区分「等其他人表态 / 请选择碰杠过 / XX 出牌中」 | ✅ |
| B4 | 切后台回来牌桌没了 | 客户端 `onDisconnect` → 1.5s 后带同一 token 重连，最多 3 次；房主按 token 认回原座位原分数 | ✅ |
| B5 | 房主退出全场黑 | 新增 `ended` 消息，房主离开时广播「房主已离开牌桌」，三家回大厅 | ✅ |
| B6 | 结算突然扣 240 分看不懂 | 每家一行算式：`10 × 2 × 4（他打了 2 张红中）= 80` | ✅ |
| B7 | 不知道自己打了几张红中 | 顶部常驻「红中东0 南1 西0 北2 · 全桌 3 张 · 倍乘 2^3」 | ✅ |
| B8 | 补牌从牌墙尾摸看不出来 | 快照新增 `lastDrawnFromTail`，尾补时显示「尾补」胶囊标记 | ✅ |
| B9 | 点一下就出牌，误触 | 改成两段式：点一下抬牌，再点同一张才打出，中间提示「再点一次打出」 | ✅ |
| B10 | 全程静音 | 新增 `Sound`：摸/打/红中/碰/杠/胡/入座 七类系统音 + 中等触感，40ms 去重防炸 | ✅ |
| B11 | 不知道听的那张还剩几张 | 听牌提示变成「听 6条(剩2) · 9条(剩1)」，按已见牌精确算 | ✅ |
| B12 | 小屏（667×375）挤 | `Metrics.isCompact`：手牌边距 40、牌宽系数 0.215、副露与牌河缩一档 | ✅ |
| B13 | 结算 14 张牌在小屏太小 | 结算手牌区可横向滚动，紧凑档牌面 30×41 | ✅ |
| B14 | 没有复盘入口 | 结算页显示「种子 0x…」+ 一键复制 | ✅ |
| B15 | 看不出谁托管谁掉线 | 名牌加「机器人」「离线」标记 | ✅ |
| B16 | 机器人 420ms 一步太慢 | 降到 300ms | ✅ |
